# Elite Cell

Sistema da assistência técnica.

## Como usar no computador

1. Clique em **Code** → **Download ZIP**
2. Extraia a pasta
3. Abra `index.html` no Chrome ou Edge

Os dados ficam salvos neste computador. Use o botão Backup.

O arquivo `.exe` de 110 MB não cabe no chat nem no GitHub comum (limite de 100 MB). Use esta versão pelo navegador.
